# Exploratory Data Analysis: Project 2

*Group : Lahoud Steven; Fernandes Anthony*

This project explores electoral results in Paris since 2007, the first year
covered by the official open data archives. We try to understand the evolution
of the political landscape in Paris through the lens of advanced techniques that
use singular value decomposition, such as PCA or CCA.

This project can be viewed [at this address](https://yapudpill.github.io/EDA-MonMaster/)
or you can render it yourself using [quarto](https://quarto.org/).

## Required R packages

- tidyverse
- arrow
- readxl
- FactoMineR
- factoextra
- gt
- sf
- generics
- broom
- CCA
